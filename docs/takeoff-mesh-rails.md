# v11 起飞边：按碰撞网格的直管分段

本轮只更换沿轨的几何分段，不恢复工程提速，也不改整关选球种、落地冲量或风扇。`launch_rule` 升版，因为轨心、接缝和脱轨时机可能改变。细节和规则依据见 [physics.md](physics.md#沿轨直段来自碰撞网格v11)。

## 怎样分段

1. 原网格管环中心给出直管轴线 [READ]。原粗层点和钢轨配对保留。配对游程选中覆盖它的网格段，管端按横截面裁切；不会在粗层步距上切一串新段。
2. 双轨取配对后抬高的轨心；两根管环数不一致时用归一弧长配准 [ASSUMED]。保留真实弯折，合并同向共线段 [DERIVED]，让沿轨方程在不变的方向上只解一次。
3. 捕获按有限直段投影，再核实实际碰撞网格的支撑。沿轨闭式、脱轨反解、接缝和轨端助跑共用新几何，映射最后仍回到粗层节点。第 3 关有一条粗层配对（lane 41）把一支的五个点配到另一支的同一个端点；保留原粗层点，但不把这一块虚构为连续双轨。周围还有别的轨心，未证明两根管在此处各自的单轨可达性等价。

弯处选择网格直管。另用两条 SR03 的实录帧做了几何对照：仅把相邻网格环两次圆拟合都一致的管段换成有限圆弧；61 段里有 14 段符合诊断条件。实录的 7 / 12 个接触帧上，两者的最近轴线距离完全相同；两条纪录的 424 / 402 个沿轨实录帧中，变化为 0 / 3 帧，最大变化 0 / 0.0343 单位。这不是圆弧动力学对照；纪录没有提供足够证据让我们用圆弧替换实际网格。详细结果为 本地输出文件（不进仓库）。
