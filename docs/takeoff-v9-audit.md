# 第 3 步第七轮：v9 解析接触核对（A 未过）

## 已替换的判定

- `sweep.py` / `takeoff.py`：以整数 PSI 的闭式球心和实际步内直弦为轨迹。先算整段界，再对无法排除的区间隔离；对棱的有限圆柱、顶点的球及对应最近点区域求交。不按物理步更新状态，也不以固定间距找接触。`triangle_edge_samples` 已删，改用 `triangle_edge_hit`。末端擦碰不再要求两个旧探针中有一个落在接触区内。
- 钢轨离轨前缀：支撑域按接触半径、法线锥及双轨反力的点积求连续区间。只豁免起点所在的连续支撑前缀，不跨越中间空隙。解析前缀不是“整根钢轨永远不挡”。
- 支撑续行：直轨按直线扫掠，固定路面按滚动闭式扫掠；路面过棱用相邻三角面法线。钢轨弯管半径来自碰撞网格管环中心（圆弧近似【假】），不由粗层每单位的三个位置估计。碰撞间隙及接触冲量的其余参数未调。
