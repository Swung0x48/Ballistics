# 第 3 步第八轮：v10 解析判定核对

## 规则和依据

- **同刻接触 [DERIVED / ASSUMED]**：先求最早根，再在同一球心收集同一接触间隙内的网格特征。法线和接触距离相同的网格接缝不重复算反力。一个接触组只占一次反弹预算；同一 PSI 内发现的新约束不再加一次自由飞行冲量或恢复冲量。多法线时，在各材质的法向分离速度不等式下，求最小速度修正；三维 KKT 条件只需考察至多三条独立活跃约束。若恢复约束互相冲突，则求无恢复的修正；无法分离或重复撞回已处理的特征不当作打通。对起点已经深入网格、没有共同接触根的拟合姿态，先按首个几何特征恢复【假】。这是起飞边的刚性球模型，不等于引擎的摩擦／多面体求解。
- **有坡度的双轨 [DERIVED]**：从两条反力的叉积得局部切向，将竖直方向投影到其法平面，解两条反力向量的 Gram 线性系统。两系数均为正且合反力满足 `WALK_NY` 才能托住。使用 v9 已有的双轨附加接触间隙，不用世界水平反力必须近平行反向来拒绝陡坡双轨。
- **种子 [DERIVED / ASSUMED]**：普通落地边可按滚动连通块收敛，沿轨种子则在查到落轨时单独登记。键含起跳站点、助跑起点、球种、钢轨链、方向、链内直段及映射节点、纵横速度区间。宽度借用 `sqrt(2g·floor)` 作为数值分辨率【假】，同一区间留最快见证，不声称不同状态互相支配。未尝试到的输入仍不是不可达证明。串边出口按实际源点和目标滚动块择代表。
- **守卫 [DERIVED / ASSUMED]**：`motion` 是助跑直段、闭式飞行、支撑滚动和绕棱／侧翻弧的独立几何。平移变换后的盒子及单摆形状使用半空间求交；变球器用球形扫掠；滑门用球到盒子或凸体的距离（直段分区二次最小化，曲线用整段界隔离交点）。单摆运动余量沿接触处切向判断【假】。`way` 用于画图和输出；合成例子及存档没有解析段时，只能把给定的线段当成原始几何。
- **固定支撑 [DERIVED / ASSUMED]**：逐个向上三角面求球心支撑棱柱，线与各棱柱交区间必须连通覆盖全段；再排除会穿入阻挡面的连续线段。裸露棱角不足以证明可新建机关底下的整条通道；钢轨证据仍走现有轨链。单摆洞口只作报告，解析消去竖直探查区间后，求环与支撑域交的角度总长，缺半环及以上才提示【假】。粗层反力平衡用水平投影凸包含原点，不再试 36 个方向，保留原 `0.001` 数值裕量。
- **导出钢轨 [DERIVED]**：不同顶点沿各自法线偏移后，是否邻接由半径的二次不等式决定。只在可改变连通性的根所划出的区间试连通分组，不枚举固定半径格点。每个管环的半径和中心仍由圆拟合得到。以原第 3 关导出网格单独复算：`Rail_07` 为 47 轴段不变，半径中位 0.330000→0.349989，端点最大差 0.000235；`Rail_08` 为 71 轴段，端点和半径不变。全量网格没有重导出，其他物体不外推。

## 采样例外和旧依赖

- 粗层落脚点网格、`rails.resample` 和依赖它的配对保留。`render.py`、`regions.py` 像素插值、单摆显示圆和 `way` 的显示折线不是判据。弧的高斯求积用于轨迹参数间时长换算；可达、接触和能量门槛均不由等距探针决定。`route.py` 的重采样属于参考线导出，不供默认区域分析或建图判定。
- 没有逐处改 `launch.py`、`staged.py`、`shortcut.py` 的旧推演或种子挑选。默认区域分析原来从 `staged` 引入 `nearest_node` / `world_for`，现在取自 `coarse` / `solve`；默认建图与区域分析没有这三个旧模块的导入。`--roll` 仍明确进入旧推演。
- **另有未闭式化的默认依赖**：`solve.graph_for → fan_lifts → ride / World.rollout` 仍生成风扇起飞边（计划第 4 步），按物理步推演并用分块退出检查。v10 给后续守卫保存风扇返回的所有原始步内弦，不再拿稀疏显示点断定遮挡；这不等于已迁移风扇本身。

## 原版纪录 / 验收

高速组的原版 `fric` 有宿主帧号、物体、接触点和法线，没有首次接触的亚步时刻。3,721 条样本都从相邻 PSI 的上一帧启动，预测窗口也限制在同一 PSI，故整数帧相等有明显筛选效应。双方都命中实录物体的 1,442 条中，各有 1,441 条报同一 PSI。新旧时间 P50 的 0.421→0.456 是在已知接触窗内比较根到帧末的距离，不能把这个退步直接解释成撞错物理步；同时位置 P50 0.10032→0.10723 仍较差。因此不能据改口径判 A 通过。

中途接触 843 段的原版误差（配对 646 段），与上一轮 v8 采样基线比，时间 P50/P90 为 1.027/9.173→0.825/9.126 PSI；位置 0.128/1.172→0.096/1.092。双方预测物体都在 `fric` 中的 353 段里，接触 PSI 一致数由 133 增为 149。原版记录到多接触点的帧在两组分别有 357、235 条；v10 在中途接触组标出 74 个多特征或合并事件。多点回调记在同一采集帧不证明亚步完全同时。逐条输入和模型对照在 本地输出文件（不进仓库），不用于拟合阈值。

第 3 关最初的三站点诊断（所有球种来源均做续行）在 772.6 秒按自己的 PID 停止，没写出整图。随后空气段诊断实测保留 `1355` 两个、`7500` 两个、`7361` 四个纸球沿轨种子；旧输入回放的两个 3-2 走法均有通向盘点平台同块的解析离轨解，但这与建图是否入选分开记录。A 未验收；没有开始 B 或 13 关全量。
