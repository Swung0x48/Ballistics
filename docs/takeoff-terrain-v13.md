# v13 共形上坡和台阶核对

本轮替换默认求解图的路面滚动、台阶边，不改钢轨接头。共形块和分球种有向边的依据见 [physics.md](physics.md#共形上坡与台阶v13)。旧粗层和旧推演入口仍可生成 v12 邻接；默认 `solve` 在共形步骤之后替换它，保留旧起飞几何提案并用原闭式验证；`launch_rule` 已换版。

## 静止判定与原版纪录

目录力比给出单键／对角双键名义角：木 36.76°／46.57°，石 16.89°／23.24°，纸 47.00°／56.60°。不是把所有坡向都乘 `√2`，而是随 `|f_x|+|f_z|` 变化。未定边按木 30.5°、石 16° 的实测保守端处理并单列；纸球没有对应实测区间【假】。

`SR01_1_14_457_264` 第 10422 → 10424 帧，在 `A02_Floor_03` 的 `(144.727,-2.692,-581.062)` 一带擦到棱。按下层约 −4.15 计，局部高度 **1.458**，实录横向进棱速度 **15.229**；有 `+x,−z` 键，竖直速度从 **+4.446** 变成 **+10.643**。用相同高度、横向速度、按键法向投影代入水平棱能量模型：静止能量差 **−10.34**，带速度 **+26.96**（单位为每单位质量的能量），和「不能静止翻、实录带速度过去」相容。实录棱是斜的、进棱前还有竖直速度，不是理想水平棱绕转；这次没有声称重现它的冲量或给它添一条静止台阶边。数据见 本地输出文件（不进仓库）。

## 3-1

在 x≈180–210 三条坡内，石球沿 +x 的普通滚动边：V 槽 **94 → 0**，世界轴近对齐的 21.8° 坡 **377 → 0**，14.6° 中间平面 **377 → 377**。用同一组粗层节点做区内有向搜索，前两条仅 v12 能从低端滚到高端，14.6° 那条两版都能到。例见 本地输出文件（不进仓库）。

近世界 +x 的 21.8° 坡，在一直给 +x 推力、按闭式阻尼滚动的诊断里，斜长 32.285，需要进坡速度至少 **14.893**；以 12 入坡只到 **23.722**。查过本地四条第 3 关原版纪录，没有石球穿过该坡的实录。`P_Trafo_Stone_02` 按目录在 `(162.787,-28.119,131.224)` 以**零速度**出球，不能继承入变球器的速度。未取得从该出球过程到这条坡脚的足够速度见证，故没有把 21.8° 坡连回去。

在第 3 关**定向图**上运行整关选球种，3-1 走 **木 → 石 → 木 → 纸**，两个断点都是 `bridge`（前段 `W164→W162`，末段 `P14→P12`）。石球有实际的普通滚动路径从 `(159,-29.37,131)` 到 `(217,-22.27,141)`：x=181–209 的路段取 z=140，是缓坡一侧沿，坡度约 **19.0–20.9°**，按朝向换算的保守上限约 **21.8–22.1°**。这不是石球爬 36° V 槽，也不是给 21.8° 轴向坡放行。第 3 关的逐节断点 **2 / 0 / 5 / 2 / 6** 只对这个定向图成立，出入球种与逐步位置见 本地输出文件（不进仓库）。
