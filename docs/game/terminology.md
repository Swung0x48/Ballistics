# 术语

中文文字（文档、报告、图上的标注）里的 Ballance 专用名词，统一用 Ballance 中文社区 wiki（ballance.jxpxxzj.cn）的说法。代码里的标识符不受影响。

| 概念 | 用 | 不用 | 备注 |
|---|---|---|---|
| checkpoint（点燃后开始下一小节的火盆） | **盘点** | 检查点 | wiki 的正式词条名是“存档点”，“盘点”是别名，两者都对；这里统一写“盘点”。开局的四团火叫“起始盘点” |
| sector（两个盘点之间的部分） | **小节**，第 N 小节，X-Y（如 1-1） | 段、扇区、区段 | |
| level | **关卡**，第 N 关 | | |
| airship（终点） | **飞船** | 飞艇、气球 | 第 12、13 关结束时接木球的是“飞碟”，是另一个东西 |
| 完成一关 | **通关** | | |
| spawn | **出生点**；球“出生” | 关卡起点 | |
| respawn | **重生点**、**重生** | 复活、复活点 | |
| 掉下去 | **死亡**、**死球** | 掉落、掉球、摔死 | 判定是球与死亡区相交 |

第 1 关几条有名字的走法（鬼躲石变、弯轨捷径、贝多芬捷径）见 [levels.md](levels.md)。

本项目自己的说法：

| 说法 | 含义 |
|---|---|
| 断点 | 粗层接不上、或跟随器走不下去的地方。细搜过了就不再是断点；没过就如实留着 |
| 粗层、细层 | 粗层是可站立位置和钢轨连成的图，只提候选；细层是在物理核里对着精确三角面算 |
| 物理核 | 手写的球的物理，一步等于引擎的一个物理步 |
| 物理步 | 引擎的一个 PSI，1/66 物理秒；每游戏秒 132 步 |
| 摆放物 | 地图上摆放的东西：机关、箱子、道具球等。推演中球不许碰它们 |
