# v12 共形路面：实现和核对

粗层体素、落脚点及 v11 的钢轨网格直管都保留。共形步骤按朝上的静态路面做 Trimesh 邻接和边界归并，按 Shapely 多边形做落点几何。拟合平面改变瞄准及路面续行；飞行的首次接触仍查原版碰撞网格。详见 [物理依据](physics.md#共形路面与可达带v12)。

## 平面块统计

| 7 | 3,634 → 1,069 | 3,990 → 1,263 |

Trimesh 的 `facets` 内部使用无量纲的半径／跨度平方阈值，不直接表示 0.3° 或 0.02。这里使用同一库的焊接、相邻面、连通分量及 `facets_boundary` 所用的唯一边原语，明确按 0.3° 和 0.02 分类。不把分别与上一个面近共面、但已经离开同一参考平面的长链合成一块；故无需与别的合并口径得到完全相同的块数。右列另外包含粗层求解加入的盘点圆台，各圆台保留原三角面组成的平面块。原导出仅建几何层用时约 0.23–0.26 s（无落脚点映射与区域分析）。第 3、5 关定向输入的路面落脚点全部有块映射。

按启动方向与块多边形的交线、该线段端点／中点、交集内部点及其代表落脚点生成有限的见证，不沿轨或飞行曲线等距取点。高速撞地状态独立保留：同块最快落地不支配另一落地的速度和方向。沿面续行时，原网格棱上径向支撑可使球心投影已经在块外；仅在球确实触着有限边界且速度向外时，把这次换块记在入段时刻，不再等待一个并不存在的未来出界根。

目前的边界：竖直状态变化明显时，钢轨可达带用可证明的外界后再反解代表，并非整条带的精确曲边；滚动区域的几何切分依赖落脚点的近邻区域【假】。测试输入里的路面节点全部归了块，若其他图存在不能归到可支撑平面的节点，诊断上走保留的旧离散候选路径，不能把它当成已实现共形的面。
